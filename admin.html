Localização e horários
Manutenção
Preencher coordenadas
Busca no Google a localização (lat/lng) dos lugares que ainda não têm — é o que faz aparecer a distância em km no card pra todo mundo. Roda uma vez; salva direto no banco (sem push).
Diagnóstico
Conferir Place IDs
Compara o endereço cadastrado com o endereço do Google Place ID de cada lugar e lista as divergências — pega casos de ID de outra unidade da mesma rede (pino no lugar errado).
Correção
Corrigir pino errado
Refaz a localização de todos os lugares com Google ID usando o próprio ID (fonte exata). Use quando um pino cair no lugar errado — normalmente é coordenada que veio de busca por endereço e pegou outra unidade da mesma rede.
Manutenção
Converter horários
Preenche a grade de horário por dia dos lugares antigos a partir do texto — sem sobrescrever quem já tem a grade preenchida.
Notificações
Envie avisos e novidades. Aparecem na aba Notificações do menu do app.
Estas são notificações dentro do app (aparecem na aba do menu, com pontinho de aviso). O envio como push no celular exige plano Blaze + Cloud Function + build nativo — por isso está marcado como “em breve”.
O Enviar teste mostra a notificação só pra esses e-mails (quando logados no app). Os admins já vêm preenchidos — pode remover.

Regras & Admins
Configure o Firebase para proteger o painel
Aplique as regras abaixo no Firebase Console → Firestore → Rules para garantir que apenas admins autorizados possam escrever na coleção places.

Publicar fotos (GitHub)

Acesso usado pra publicar as fotos dos lugares direto na pasta fotos/ do site. É configurado uma vez só e vale pra todos os lugares. Fica salvo apenas neste navegador — nunca vai pro repositório. Se você trocar de computador, precisa configurar de novo lá.

Admins com acesso ao painel

Quem pode entrar e editar. Adicione ou remova por e-mail (precisa ser conta Google). O primeiro admin é criado uma vez no Console; daqui pra frente, é tudo por aqui.

Regras de segurança do Firestore

rules_version = '2';

// ─────────────────────────────────────────────────────────────────────
// Firestore Security Rules — OndeIr Curitiba
//
// ESTA é a barreira de segurança real do app (o painel admin no navegador
// é só interface). REVISE e TESTE no "Rules Playground" do console do
// Firebase antes de publicar (Firestore → Regras → Publicar).
//
// Princípios:
//   • Conteúdo (places, categories, app_config): leitura pública, escrita
//     só de admin — EXCETO o contador _likes do lugar, que o app incrementa
//     por usuário logado (regra por campo abaixo).
//   • Admin = existe um doc em /admins com id == e-mail do usuário logado.
//   • Dados de cada usuário: só o próprio dono lê/escreve.
//   • Contadores sociais/comentários: leitura pública; cada um escreve o seu.
//   • Tudo o que não estiver liberado explicitamente é NEGADO.
// ─────────────────────────────────────────────────────────────────────

service cloud.firestore {
  match /databases/{database}/documents {

    // ── Helpers ──────────────────────────────────────────────────────
    function signedIn() { return request.auth != null; }
    function isOwner(uid) { return signedIn() && request.auth.uid == uid; }
    // Admin: o e-mail do usuário logado é o id de um doc em /admins.
    function isAdmin() {
      return signedIn()
        && request.auth.token.email != null
        && exists(/databases/$(database)/documents/admins/$(request.auth.token.email));
    }
    // A atualização mexe SOMENTE nos campos listados?
    function onlyChanges(keys) {
      return request.resource.data.diff(resource.data).affectedKeys().hasOnly(keys);
    }

    // ── Conteúdo do app ──────────────────────────────────────────────
    // Lugares: leitura pública. Escrita de conteúdo só admin; mas um usuário
    // logado pode atualizar APENAS o contador _likes (curtir/descurtir).
    match /places/{id} {
      allow read: if true;
      allow create, delete: if isAdmin();
      // Usuário só mexe no _likes e só em ±1 por escrita (evita setar
      // um número arbitrário tipo 999999 ou negativo).
      allow update: if isAdmin()
                    || (signedIn() && onlyChanges(['_likes'])
                        && request.resource.data._likes is int
                        && request.resource.data._likes >= 0
                        && (request.resource.data._likes - resource.data.get('_likes', 0)) >= -1
                        && (request.resource.data._likes - resource.data.get('_likes', 0)) <= 1);
    }

    match /categories/{id} { allow read: if true; allow write: if isAdmin(); }
    match /app_config/{id} { allow read: if true; allow write: if isAdmin(); }

    // ── Admins ───────────────────────────────────────────────────────
    // Cada um lê o próprio doc (o painel usa isso pra saber se é admin);
    // admin lê todos. Só admin adiciona/remove admins.
    match /admins/{email} {
      allow read:  if signedIn() && (request.auth.token.email == email || isAdmin());
      allow write: if isAdmin();
    }

    // ── Dados privados por usuário (só o dono) ───────────────────────
    match /favorites/{uid}/places/{pid}       { allow read, write: if isOwner(uid); }
    match /want_today/{uid}/places/{pid}      { allow read, write: if isOwner(uid); }
    match /skipped/{uid}/places/{pid}         { allow read, write: if isOwner(uid); }
    match /been_there/{uid}/places/{pid}      { allow read, write: if isOwner(uid); }
    match /xp_events/{uid}/events/{eid}       { allow read, write: if isOwner(uid); }
    match /likes_by_user/{uid}/places/{pid}   { allow read, write: if isOwner(uid); }
    match /ratings_by_user/{uid}/places/{pid} { allow read, write: if isOwner(uid); }

    // Perfil: leitura por qualquer logado (nome/avatar em comentários);
    // escrita só o dono.
    match /user_profiles/{uid} {
      allow read:  if signedIn();
      allow write: if isOwner(uid);
    }

    // Presença por usuário (createdAt/lastSeen) — alimenta as métricas de
    // usuários do admin. Cada um só escreve o seu; só admin lê a coleção toda.
    match /users_meta/{uid} {
      allow read:  if isAdmin();
      allow create, update: if isOwner(uid);
    }

    // ── Contadores sociais por lugar (id do doc = uid do usuário) ─────
    // Likes contam por dia: id `uid_AAAA-MM-DD` (o formato antigo, só o
    // uid, continua aceito). O dono é sempre o trecho antes do "_".
    match /likes/{placeId}/users/{docId} {
      allow read: if true;
      allow write: if signedIn() && docId.split('_')[0] == request.auth.uid;
    }
    match /saves/{placeId}/users/{uid}   { allow read: if true; allow write: if isOwner(uid); }
    match /visits/{placeId}/users/{uid}  { allow read: if true; allow write: if isOwner(uid); }
    match /ratings/{placeId}/votes/{uid} { allow read: if true; allow write: if isOwner(uid); }

    // Resumo de nota (avg/count) do lugar: o app calcula no cliente e grava
    // no doc pai. Leitura pública; escrita por qualquer logado (limitação de
    // um app client-side — o cálculo não é confiável, só o total de votos é).
    match /ratings/{placeId} {
      allow read:  if true;
      allow write: if signedIn() && onlyChanges(['avg', 'count']);
    }

    // Docs "pai" de contadores que o app NÃO escreve diretamente:
    // leitura pública, escrita bloqueada.
    match /likes/{placeId}   { allow read: if true; allow write: if false; }
    match /saves/{placeId}   { allow read: if true; allow write: if false; }
    match /visits/{placeId}  { allow read: if true; allow write: if false; }
    match /comments/{placeId}{ allow read: if true; allow write: if false; }

    // ── Comentários ──────────────────────────────────────────────────
    // Leitura pública; cria só o próprio autor; edita/apaga o autor ou admin.
    match /comments/{placeId}/items/{id} {
      allow read:   if true;
      // Cria só o próprio autor, com campos validados no servidor:
      // texto 1–500 chars, estrelas 1–5 (ou null), nome ≤ 80, foto só
      // URL https (ou null), e nenhum campo além dos esperados.
      allow create: if signedIn()
        && request.resource.data.userId == request.auth.uid
        && request.resource.data.keys().hasOnly(
             ['text', 'stars', 'userId', 'userName', 'userPhoto', 'createdAt'])
        && request.resource.data.text is string
        && request.resource.data.text.size() >= 1
        && request.resource.data.text.size() <= 500
        && (request.resource.data.stars == null
            || (request.resource.data.stars is int
                && request.resource.data.stars >= 1
                && request.resource.data.stars <= 5))
        && request.resource.data.userName is string
        && request.resource.data.userName.size() >= 1
        && request.resource.data.userName.size() <= 80
        && (request.resource.data.userPhoto == null
            || (request.resource.data.userPhoto is string
                && request.resource.data.userPhoto.size() <= 500
                && request.resource.data.userPhoto.matches('https://.*')));
      allow update, delete: if isAdmin()
        || (signedIn() && resource.data.userId == request.auth.uid);
    }

    // ── Denúncias de comentários (exigência da Google Play p/ UGC) ───
    // Qualquer logado pode denunciar; ler e resolver a fila é só admin.
    match /comment_reports/{id} {
      allow read:   if isAdmin();
      allow create: if signedIn()
        && request.resource.data.reporterId == request.auth.uid
        && request.resource.data.status == 'pending'
        && request.resource.data.keys().hasOnly(
             ['placeId', 'commentId', 'commentText', 'commentUserId',
              'commentUserName', 'reporterId', 'status', 'createdAt'])
        && request.resource.data.commentText is string
        && request.resource.data.commentText.size() <= 300;
      allow update, delete: if isAdmin();
    }

    // ── Sugestões de correção (enviadas pelos usuários) ──────────────
    // Qualquer usuário logado pode ENVIAR uma sugestão de correção de um
    // lugar. O doc nasce como 'pending' e marcado com o uid de quem enviou.
    // Ler a fila e aprovar/descartar é só admin. Aplicar a correção no lugar
    // usa a regra de /places (isAdmin), não esta.
    match /corrections/{id} {
      allow read:   if isAdmin();
      allow create: if signedIn()
                    && request.resource.data.userId == request.auth.uid
                    && request.resource.data.status == 'pending';
      allow update, delete: if isAdmin();
    }

    // ── Padrão: nega o que não foi liberado acima ────────────────────
    match /{document=**} { allow read, write: if false; }
  }
}
