Regras & Admins
Configure o Firebase para proteger o painel
💡
Aplique as regras abaixo no Firebase Console → Firestore → Rules para garantir que apenas admins autorizados possam escrever na coleção places.

1. Adicionar admins autorizados

Crie uma coleção admins no Firestore. Cada documento deve ter o e-mail do admin como ID e um campo role: "admin".

Firestore → Adicionar coleção: "admins"
Documento ID: seuemail@gmail.com
Campo: role = "admin"

2. Regras de segurança do Firestore

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Apenas admins leem a lista de admins
    match /admins/{email} {
      allow read: if request.auth != null
                  && request.auth.token.email == email;
      allow write: if false;
    }

    // Lugares: leitura pública, escrita só para admins
    match /places/{placeId} {
      allow read: if true;
      allow write: if request.auth != null
                   && exists(/databases/$(database)/documents/admins/$(request.auth.token.email));
    }

    // Favoritos dos usuários
    match /favorites/{userId}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }

    // Comentários
    match /comments/{document=**} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null
                            && request.auth.uid == resource.data.uid;
    }
  }
}

3. Atualizar o index.html

Após migrar, substitua o array const P = [...] do index.html por este código que busca do Firestore:

// Substitua "const P = [...]" por:
let P = [];

async function loadPlacesFromFirestore() {
  const { getFirestore, collection, getDocs } =
    await import('https://www.gstatic.com/firebasejs/10.12.0/firebase-firestore.js');
  const db = getFirestore();
  const snap = await getDocs(collection(db, 'places'));
  P = snap.docs.map(d => ({ id: d.id, ...d.data() }));
  filtered = [...P];
  renderCard();
  renderProgress();
  renderCats();
}

// Chame no init():
loadPlacesFromFirestore();
